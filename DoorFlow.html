Overview

DoorFlow Ruby SDK for access control and door management

This is the main entry point for the DoorFlow SDK. Configure your API credentials here before making API calls.

Examples:

Basic configuration with OAuth

require 'doorflow'

# After completing OAuth flow
DoorFlow.access_token = auth.access_token

# Now you can use the SDK
people = DoorFlow::Person.list
person = DoorFlow::Person.create(
  first_name: 'John',
  last_name: 'Doe',
  email: 'john@example.com'
)

Configuration with custom API base

DoorFlow.access_token = auth.access_token
DoorFlow.api_base = 'https://api.doorflow.com'

Block-style configuration

DoorFlow.configure do |config|
  config.access_token = auth.access_token
  config.scheme = 'https'
  config.host = 'api.doorflow.com'
end

.configure {|config| ... } ⇒ DoorFlow::Configuration

Configure the DoorFlow SDK using a block

This provides access to the underlying configuration object for advanced configuration options. For most use cases, setting api_key and api_base directly is sufficient.

Examples:

Advanced configuration

DoorFlow.configure do |config|
  config.access_token = 'your_api_key'
  config.scheme = 'https'
  config.host = 'api.doorflow.com'
  config.debugging = true
end
