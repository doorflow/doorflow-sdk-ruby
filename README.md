# doorflow API SDK for ruby

Official ruby SDK for the doorflow API.

## Installation

```ruby
# Add to your Gemfile
gem 'doorflow_api'

# Or install directly
gem install doorflow_api
```

## Usage

```ruby
require 'doorflow_api'

client = DoorFlowApi::Client.new(
  client_id: 'your_client_id',
  client_secret: 'your_client_secret'
)
```
