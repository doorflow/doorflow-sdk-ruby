Overview

Raised when rate limit is exceeded (HTTP 429)

This error includes information about when the rate limit resets, allowing for proper backoff and retry logic.

Examples:

Handling rate limits with retry

begin
  doorflow.people.list
rescue DoorFlow::Errors::RateLimitError => e
  if e.retry_after
    sleep(e.retry_after)
    retry
  end
end

Exponential backoff

retries = 0
begin
  doorflow.people.list
rescue DoorFlow::Errors::RateLimitError => e
  retries += 1
  raise if retries > 3
  sleep(e.retry_after || (2 ** retries))
  retry
end
